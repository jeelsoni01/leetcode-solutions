# 📚 How I Solve Problems

For every problem, I try to understand five things:

### 01 — Understand

What exactly is the problem asking?

### 02 — Brute Force

What is the simplest solution I can think of?

### 03 — Identify the Pattern

Can I recognize a known DSA pattern?

### 04 — Optimize

Can I improve:

```text
Time Complexity
        +
Space Complexity
```

### 05 — Edge Cases

I don't consider a solution complete until I think about the unusual cases.

```text
Empty / Minimum Input
        ↓
Duplicates
        ↓
Already Sorted
        ↓
Reverse Sorted
        ↓
Single Element
        ↓
Boundary Values
```

# ⚙️ Automation

This repository uses **LeetSync + GitHub Actions**.

```text
                    🧑‍💻 Me
                      │
                      │ Solve
                      ↓
                  🟠 LeetCode
                      │
                      │ LeetSync
                      ↓
                🐙 GitHub Repo
                      │
                      ↓
              ⚙️ GitHub Actions
                      │
                      ↓
             🐍 update_readme.py
                      │
              ┌───────┴───────┐
              ↓               ↓
         Count Problems    Update Stats
              │               │
              └───────┬───────┘
                      ↓
                  📊 README
```

This means I can focus on **solving problems**, while the repository handles the progress tracking.
